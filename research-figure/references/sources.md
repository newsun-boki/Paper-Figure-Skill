# 方法来源与取舍

查阅日期：2026-10-14。以下用于归属和复核；本 skill 无需下载这些仓库才能运行。

- [彭思达：Learning Research](https://github.com/pengsida/learning_research)：科研问题、方案、实验和呈现的整体规划。原仓库链接的部分 Notion 页面本次无法直接读取；具体写作条目结合下列公开整理版核对。
- [HughYau：论文画图与画表](https://github.com/HughYau/pengsida-learning-research-skills/blob/main/paper-writing/references/figures-and-tables.md)：先梳理输入、操作和中间输出，再确定布局；突出真正的新模块。
- [Master-cai：Method Writing Guide](https://github.com/Master-cai/Research-Paper-Writing-Skills/blob/main/research-paper-writing/references/method.md)：检查模块的动机、设计和可支持的优势，核对整体逻辑与术语一致性。
- [HughYau：paper-narrative](https://github.com/HughYau/pengsida-learning-research-skills/blob/main/paper-narrative/SKILL.md) 与 [figure-composer](https://github.com/HughYau/pengsida-learning-research-skills/blob/main/figure-composer/SKILL.md)：整套图的故事与单图布局分别审视，查看组合后的实际渲染并修正具体缺陷。该仓库注明其绘图执行层来自 claude-science，不能把这些执行工具一并归为彭思达本人创作。

本 skill 独立编写，未复制上述仓库的代码、模板或图像，也不代表其作者背书。

本工作流的具体选择来自用户需求与实际复刻经验：GPT Image 出视觉稿、Figma / PPT 原生结构与局部位图混合、以读者理解和核心贡献为准、复刻时以原 PNG 为基准。突出新意必须与逻辑清晰、证据准确同时成立；不采用牺牲读者理解来突出新意的表述。

不强制固定 panel 数、12 列网格或统一会议风格，不随着迭代降低正确性标准。至少 5 轮是这套完整绘图 / 复刻流程的质量偏好，不是来自文献的质量保证。
